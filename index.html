From theory to practice

Understand CSS positioning, one move at a time.

Position Quest is a browser-based learning tool by TechWebster. Practice CSS offsets, positioning and stacking with live visual feedback. No account or installation is needed; your progress is saved in this browser.

Relative positioning

Use position: relative with top and left to offset an element from its normal position while keeping its original space in the layout.

Absolute positioning

Take an element out of normal flow with position: absolute. Practice edge offsets and centering within a positioned ancestor.

Fixed positioning

Use position: fixed to anchor an element to the viewport in these challenges, then combine offsets and transforms to center it.

Stacking with z-index

Move the hero above or below a crate. Explore how z-index controls the order of elements within a stacking context.

How to play

Read the level brief, type CSS in the editor and watch the hero move. Match the target to unlock the next draft. Use hints when you get stuck, or open the cheat sheet for a quick reference.

Position cheat sheet

position: static;
Default. The box sits in normal flow — top / right / bottom / left do nothing.
position: relative;
Offset from where it would be. Flow keeps its original space. Enables z-index and acts as the anchor for absolute children.
position: absolute;
Removed from flow. Anchored to the nearest positioned ancestor (else the page). top/right/bottom/left measure from that ancestor's edges.
position: fixed;
Removed from flow. Usually anchored to the viewport. Certain ancestors, such as transformed elements, can establish its containing block instead.
position: sticky;
Relative until it crosses a scroll threshold (top: 0 etc.), then it sticks, within its parent.
z-index
Stacking order within a stacking context. Works on positioned elements and flex or grid items; higher values paint above lower ones in the same context.
Tricks
Center anything: position:absolute; inset:0; margin:auto; or left:50%; top:50%; transform:translate(-50%,-50%);
